# Aryan Kumar — Portfolio V3

Creative standalone static portfolio. This version is separate from V2 and V4.

## Files
- `index.html` — HTML source, formatted for readability
- `styles.css` — styling
- `app.js` — interactivity and the Simon mini-game
- `assets/resume.pdf` — resume

## Deploy on Vercel
1. Create a separate new GitHub repository, for example `portfolio-v3`, and upload the files and `assets` folder at the repository root.
2. At https://vercel.com/new, import the new repository.
3. Select Framework Preset: **Other**, Root Directory: `./`, and leave build command disabled.
4. Deploy. This is a static site: no environment variables are required.

Do not import the existing `portfolio` repository if that should continue to host V2.
